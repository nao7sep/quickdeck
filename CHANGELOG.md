All notable changes to this project will be documented in this file.

## [Unreleased]

### Added

- Pane headers carry a gradient derived from their own colour.
- Snapshots open as a browsable list, newest first, with the selected snapshot's full text beside it and a Copy control that puts it on the clipboard.

### Changed

- Snapshot search narrows that list instead of being the only way to reach a snapshot. The menu item and modal are now named Snapshots.
